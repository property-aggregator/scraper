# Portals rules

This note explains the most important rules for the portals we scrape.

## 1. Otodom

### External ID

External ID is extracted from the offer URL. Example:

`.../mieszkanie-3-pok-ID4AIgX` -> `ID4AIgX`

### Location

Location may sometimes be empty, especially for foreign listings.
Example of a complete location value: 

`"al. Niepodległości, Pruszków, pruszkowski, mazowieckie"`
